# 🎓 AI PhD Vacancy & Academic Lead Finder

An automated, cloud-hosted pipeline that monitors live PhD vacancies across European university boards, international academic portals, and Telegram graduate recruitment channels. Matches are evaluated using Google Gemini against a personalized research taxonomy and delivered directly to your Telegram chat.

Runs **100% free** on **GitHub Actions** without requiring local servers, active local connections, or paid proxy setups.

---

## 📌 What This Repository Does

1. **Telegram Channels:** Scrapes graduate recruitment channels (e.g., `@expertapply`, `@EuropeanPhD`, `@ApplyDaily`).
2. **Academic Portals:** Scrapes live vacancy listings directly from:
* **EURAXESS** (EU Horizon & MSCA fellowships)
* **FindAPhD** (Global PhD database)
* **jobs.ac.uk** (UK university vacancies)
* **AcademicTransfer** (Netherlands university system)
* **AcademicPositions** (European research boards)


3. **AI Evaluation (Google Gemini):** Each vacancy text is evaluated against your research background. Relevant positions are scored and categorized into priority tiers.
4. **Instant Alerts:** Sends structured notifications directly to your private Telegram chat with full vacancy links, match rationales, and snippet previews.
5. **Deduplication:** Maintains an automated cache (`data/seen_posts.json`) to prevent duplicate alerts across cycles.

## 🚀 Setup Guide (For Forking / New Users)

### 1. Fork This Repository

Click the **Fork** button at the top-right of this repository to create a copy under your GitHub account.

---

### 2. Configure Telegram Credentials

The bot uses Telegram's Bot API to deliver real-time notifications to your phone:

1. **Create a Bot & Get Token:**
* Open Telegram and message [@BotFather](https://t.me/BotFather).
* Send `/newbot`, follow the name prompts, and copy your API Token (e.g., `7891234567:AAH...`).


2. **Get Your Numeric Chat ID:**
* Message [@userinfobot](https://t.me/userinfobot) on Telegram and send `/start`.
* Copy the numerical ID returned (e.g., `123456789`).


3. **Activate the Bot:**
* Open your newly created bot in Telegram and press **Start**. (Bots cannot message you first until you start them).



---

### 3. Get a Free Google Gemini API Key

1. Go to [Google AI Studio](https://aistudio.google.com/).
2. Sign in with your Google account.
3. Click **Get API key** $\rightarrow$ **Create API key**.
4. Copy the generated key string (`AIzaSy...`).

---

### 4. Add GitHub Secrets

Store your keys securely so GitHub Actions can access them during scheduled runs:

1. In your forked repository, click **Settings** (top navigation bar).
2. On the left sidebar, click **Secrets and variables** $\rightarrow$ **Actions**.
3. Click **New repository secret** for each of the following 3 variables:

| Secret Name | Where to Find It | Example Value |
| --- | --- | --- |
| `TG_BOT_TOKEN` | Generated by `@BotFather` | `7891234567:AAH_xYz...` |
| `TG_CHAT_ID` | Numeric ID from `@userinfobot` | `123456789` |
| `GEMINI_API_KEY` | Generated in Google AI Studio | `AIzaSyD...` |

---

### 5. Enable GitHub Actions Write Permissions

The runner commits the updated `data/seen_posts.json` cache back to your repository after each run:

1. Go to repository **Settings** $\rightarrow$ **Actions** $\rightarrow$ **General**.
2. Scroll down to **Workflow permissions**.
3. Select **Read and write permissions**.
4. Click **Save**.

## 🛠 Customizing for Your Own Research Profile

To tailor the finder to your degree, thesis, or field of interest, edit the configuration variables inside `main_cloud.py`.

### 1. Keyword Pre-filter (`BROAD_PATTERNS`)

This regex filter discards completely unrelated posts before sending them to the Gemini API, preserving your free rate limits:

```python
BROAD_PATTERNS = [
    # Add your field's core terminology
    r"robotics", r"slam", r"control systems", r"reinforcement learning",
    r"autonomous", r"computer vision", r"machine learning",
    
    # Non-English / Local terms if scanning regional channels
    r"دکتری", r"فاند", r"بورسیه", r"پوزیشن"
]

```

### 2. Disqualifiers (`EXCLUDE_PATTERNS`)

Add terms that should immediately reject a post:

```python
EXCLUDE_PATTERNS = [
    r"language course", r"visa consultant", r"postdoc",
    r"organic chemistry", r"molecular biology"
]

```

### 3. Academic Portal Queries (`ACADEMIC_SEARCH_QUERIES`)

These terms are sent directly to the search endpoints of academic boards (FindAPhD, jobs.ac.uk, EURAXESS):

```python
ACADEMIC_SEARCH_QUERIES = [
    "mobile robotics",
    "reinforcement learning control",
    "SLAM autonomous navigation",
    "embedded computer vision"
]

```

### 4. Gemini Evaluator Prompt (`SYSTEM_PROMPT`)

Define your research background, target tiers, and disqualifiers:

```python
SYSTEM_PROMPT = """You are an expert academic evaluator. Assess if a PhD vacancy post matches the candidate's research profile.

Candidate Profile:
- Tier 1 (Direct Match): Mobile robotics, SLAM, LiDAR-inertial odometry, reinforcement learning for quadruped/legged robots.
- Tier 2 (Adjacent): Optimal control, trajectory optimization, embedded computer vision, ROS2 perception pipelines.
- Tier 3 (Hardware): Low-power edge compute (Jetson, FPGA), real-time sensor fusion.
- Disqualifiers (REJECT): Pure theoretical math without robotics, soft robotics/materials, industrial manufacturing, language courses.

Respond ONLY in valid JSON:
{
  "is_relevant": true,
  "tier": 1,
  "confidence_score": 9,
  "title": "Short title",
  "key_topics": ["topic1", "topic2"],
  "reason": "1-line explanation of fit"
}"""

```

## ⏱ Execution Schedule

* **Automatic:** Runs once every 24 hours at `06:17 UTC` via GitHub Actions (`.github/workflows/phd_finder.yml`).
* **Manual Trigger (On-Demand):**
1. Go to your repo on GitHub.
2. Click the **Actions** tab.
3. Select **PhD Finder Daily Agent** from the left list.
4. Click **Run workflow** $\rightarrow$ **Run workflow** (green button).
